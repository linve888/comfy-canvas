# 正向提示词写法（Qwen-Image-2.1 / H3 适用）

## 为什么负向没用

不是"效果弱"，是数学上不存在。

**Qwen-Image-2.1**：`CFGGuider cfg=1.0`。CFG 公式是

```
out = neg + cfg × (pos − neg)
```

代入 cfg=1：`out = neg + pos − neg = pos`。负向分支被完全抵消。

**H3**：用的是 `BasicGuider`，输入只有 `model` 和 `conditioning`，**根本没有 negative 输入口**。

这两个都是蒸馏加速模型，cfg=1 是它们快的原因，代价就是没有负向引导。

### 实测证据（2026-11-05）

同提示词、同参考图、同种子 `123456789`，只改负向：

| 指标 | 结果 |
|---|---|
| 差异包围盒 | `None` |
| 通道值总和 | **0** |
| 最大单通道差 | **0** |
| 有差异的采样点 | **0 / 3,170,304 = 0.000%** |

一张负向填了「人物 人脸 手指 文字 水印 低质量 模糊 变形 动漫 卡通 多余肢体」，一张留空，**输出逐像素完全相同**。

## 铁律

**只写画面里有什么，不写画面里没有什么。**

模型没有负向分支，它只会照着你的词去生成。你写「不要出现人物」，它读到的是「人物」；你写「不要乱码文字」，它读到的是「文字」。**提一次就是给了一次出场机会。**

正确做法不是"禁止什么"，而是**用具体物件把画面占满，让不该出现的东西没有位置**。

## 三个最常犯的坑

**1. "保持 X 不变" —— 这条在 cfg=1 模型上基本无效**

"不变"是个相对概念，模型没有"原图基准"的概念（Qwen Edit 的 latent 是 zeros，全靠参考图条件）。它不知道要跟什么比。

改成**逐项列举**：「门厅、玻璃门、壁灯、台阶、扶手」——把要保的都点一遍。

**2. 越强调越容易出现**

「不要有人」在三张图里两次侥幸没出人，第三次就出了半个人影。这不是随机，是你把「人」这个词喂进去了。

**3. 环境描写会压过主体**

之前 EP01 有个空镜，提示词写了 `deep shadows` / `vanishing into the dark`，出来整帧全黑，什么都看不见。改成「正常曝光，台阶与墙面细节清晰可辨」立刻正常。

**描述光影要说"哪里亮、亮到什么程度"，而不是"哪里暗"。**

## 那我们之前写的 prompt 怎么办

`batch-render/data/EP01_anchor.csv` 和 `EP01_video.csv` 里有大量「画面中不要出现任何人物」。这些：

- **已经出图的**：改文本不会改变已有产物，不用动
- **以后要重跑或复用的**：按上表改成正面描述再跑

画布现在已经会在提示词里检测到否定表述时给黄色警告（`不要 / 不能 / 禁止 / 避免 / 不出现 / no / without / avoid`），看到就改。

## 验证方法

想自己验证某个模型吃不吃负向，用同种子跑两次、只改负向、比像素：

```python
from PIL import Image, ImageChops
import numpy as np
a, b = Image.open(p1).convert('RGB'), Image.open(p2).convert('RGB')
d = np.asarray(ImageChops.difference(a, b), dtype=np.int16)
print('差异包围盒', ImageChops.difference(a, b).getbbox())
print('通道值总和', int(d.sum()), '最大单通道差', int(d.max()))
```

`getbbox()` 返回 `None` 就是完全一致，负向对结果零影响。
